# Работа ИИ в этом проекте

- Сначала ищи нужные файлы, затем читай только необходимые фрагменты; не перечитывай неизменённые файлы.
- Своди вывод команд к минимуму. Не выводи `Library`, `Temp`, сборки и длинные логи целиком.
- Делай небольшие связанные изменения; объясняй решения простыми словами, чтобы оба автора могли поддерживать код.
- Не пропускай проверки, нужные для доказательства результата; сокращай только лишнее чтение и повторную работу.
- В конце этапа обновляй `PROJECT_STATE.md`: результат, изменённые файлы, проверки, проблемы и следующий точный шаг. Не записывай секреты.
- Git: работай в ветке `feature/*` от `main`, коммить мелко; перед PR проверь компиляцию проекта; в `main` не коммить напрямую. Подключение второго автора описано в `ONBOARDING.md`.
