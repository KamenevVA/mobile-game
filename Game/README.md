# Threadlight (prototype)

Unity project placeholder for the first playable prototype. The editor creates `Assets/`, `Packages/`, and `ProjectSettings/` when the project is initialized from Unity Hub.

Working prototype: portrait 2D color-thread routing puzzle. Scope is one mechanic, a short tutorial, and a small hand-authored level set. No ads, IAP, accounts, or network services in the first playable build.

See the project root `PROJECT_STATE.md` and `MARKET_RESEARCH_AND_GAME_CONCEPT.md` before changing scope.
