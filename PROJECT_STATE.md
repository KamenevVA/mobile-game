# Состояние проекта

## Цель

Подготовить для двух новичков практический план первой мобильной игры: изучить рынок простых игр, выбрать движок и идею, подобрать и установить полезные AI-инструменты, определить монетизацию и подготовить релиз Android-игры, проверенной на HONOR X8b.
